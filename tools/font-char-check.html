字体字符校验

选择一个 .ttf / .otf 字体，读取它的 Unicode cmap， 逐字符检查字符串里的每个字是否都被这个字体覆盖，并列出缺失字符的编码、出现次数与位置。

选择字体并输入字符串后，这里会用所选字体逐字符显示包含情况。

缺失字符明细 0 种 / 0 处

选择字体并输入字符串后，缺失的字符会按编码列在这里。

覆盖情况取自字体 cmap 表中可用的 Unicode 映射（格式 0 / 4 / 6 / 12 / 13），不涉及 GSUB/GPOS 等排版表， 因此只能判断“字体里有没有这个字的映射”，不代表该字在任意软件里的实际排版效果； 换行、制表符等控制字符不参与校验；.ttc 字体集合只读取其中的第一个字库。 字体文件只在当前浏览器内解析，不会上传。
